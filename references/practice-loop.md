# 实践循环：从实践中来，再回到实践中去

## 0. 一句话

不是“先学知识，再练习”，是**先入境做一次，从结果里长出知识，再用知识做第二次**；一次不够，反复循环。

原则不变：能力 + 求知欲。这一份讲的是方法，思想依据是毛泽东《人的正确思想是从哪里来的？》（1963）。

## 1. 认识论骨架

三条，按顺序：

1. **知识只能从实践中来。** 不是天上掉的，也不是头脑里固有的；是人在做事、交往、实验中，先得到感性材料。
2. **两次飞跃。** 感性材料积累多了，飞跃成理性认识（第一次）；理性认识回到实践、看能不能得到预期结果（第二次）。第二次比第一次更重要——只有它能检验第一次。
3. **反复循环。** 一个正确的认识，往往要经过“实践 → 认识 → 实践 → 认识”的多次反复，才能完成。

原文（节选）：

> 人的正确思想，只能从社会实践中来……
> 一个正确的认识，往往需要经过由物质到精神，由精神到物质，即由实践到认识，由认识到实践这样多次的反复，才能够完成。
> —— 毛泽东《人的正确思想是从哪里来的？》（1963）

我们只取这个**认识论结构**，不搬文章里的政治内容。

## 2. 六步（第一次在历史，第二次在当代）

0. **调查**：先弄清他的真实处境——想做什么、手上有什么、卡在哪、能投入多少。入境不是编一个场景，是从他的真实条件里长出来。
1. **历史入境**：给一个生动的历史处境——谁、在什么约束下、要解决什么问题、这次实践要达成什么。让他推演、批判、创新，不是旁观。
2. **第一次实践**：做一个具体的选择、计算、设计或判断。带着背景和目的去做，**不是盲猜**。
3. **看见**：结果如何？和预期差在哪？先让他说看到了什么，不要替他总结。
4. **命名**：理论在此刻出现，解释刚才发生了什么；**先让他试着说出规律**，老师再补名字和边界。
5. **当代再用**：把知识放回今天——先做“当代入境”（今天的场景、工具、约束、前沿问题），再做第二次实践。这一次是检验，不只是练手。

对应两次飞跃：

- 历史入境 + 第一次实践 + 看见 = 积累感性材料；
- 命名 = 第一次飞跃（感性 → 理性）；
- 当代入境 + 第二次实践 = 第二次飞跃（理性 → 当代实践），也是检验；
- 循环 = 第二次实践产生新的感性材料，进入下一轮，每轮高一级。

## 2.5 两次实践，两种现场

| | 第一次实践 | 第二次实践 |
|---|---|---|
| **现场** | 历史现场：当时的人被什么卡住 | 当代现场：今天的真实问题、工具、约束 |
| **目的** | 推演智慧怎么来的；允许批判、改写、创新 | 检验知识在当代还成不成立、能不能迁移 |
| **产物** | 一个判断、推导、设计、争论 | 一个当代方案、代码、决策、实验 |
| **失败** | 可能是历史条件不同，也可能想法本身错 | 可能是知识边界、工程约束、当代条件不同 |
| **不能做** | 把历史讲成故事会 | 换个数字再算一遍，冒充“当代应用” |

**第二次实践要面向现代化、面向未来、面向当代前沿科学与工程。** 不是“再练一道”，是把刚命名的知识放回今天，看它还能不能打。

## 2.6 怎么找当代场景

按可信度从高到低：

1. **他自己的真实工作/项目/生活**：手上的代码、数据、决策、产品、论文。
2. **公开的工程案例/论文/开源项目**：当前工具、当前版本、当前数据；引用标来源与日期。
3. **公共数据/可复现实验**：能跑、能对照、能验证。
4. **找不到就说不确定**：不要编“某公司”“某前沿”；宁可退回到一个可验证的小场景。

`web` 模式下可以查当前资料；`local` 模式下用本地材料和模型知识，并标明不确定。

## 2.7 前沿的分寸

- **区分成熟应用与探索中**：能上生产、还在论文里、只是概念，三档要说清。
- **不装懂**：不知道当前 SOTA、不知道某个工具的最新版本，就说不知道。
- **不追热点**：热点不是教学理由；与当前问题相关才用。
- **标来源与日期**：工程案例、论文、标准，写清出处和时间；网页内容按 `[W:]` 规则缓存引用。
- **前沿也会过时**：今天的前沿，明年可能是常识或错误；教的是“怎么判断”，不是“记住结论”。

## 3. 第一次实践的三件套

缺一个，就会退化成“盲猜题”或“应用题”：

- **背景**：为什么会有这个问题？当时的人被什么卡住？
- **目的**：这次实践要达成什么？一个可见结果，或一个明确的判断。
- **角色 / 约束**：你是谁？手上有什么？不能做什么？

不是“你猜 TCP 要几次握手？”，而是“你是 1970 年代的网络工程师，两台机器要传文件，线路会丢包、会重复。你只有‘发’和‘收’。先设计一个握手，两次够吗？”

## 4. 材料要够，再飞跃

感性材料不够，飞跃就是拍脑袋。

- 命名之前，尽量有 **2–3 个具体观察/案例/变体**：同一规律在不同条件下都出现，才值得命名。
- 一个数据点只能算轶事，不能算规律；一次成功/失败也不够。
- 材料可以是：跑出来的结果、画出来的图、算出来的数、别人的反馈、历史上的多个案例。
- 但也不要收集到瘫痪：够解释当前问题就停，剩下的留给下一轮。

## 5. 三类实践

不要把“实践”窄化成写代码或做题。至少三类：

| 类型 | 做什么 | 例子 |
|---|---|---|
| **造物**（生产/工程） | 做出一个能跑、能用、能看的东西 | 跑通脚本、搭一个电路、写一篇文章 |
| **交往**（社会） | 一次真实的沟通、说服、协作、教学 | 给外行讲清、说服同事、教 AI |
| **实验**（科学实验） | 一个可验证的预测、对照、复现 | 改一个参数、做 A/B、复现结果 |

三类都可以是“第一次实践”。选哪类，看他的目标和真实条件。

## 6. 失败怎么读

失败不是“再讲一遍”的信号，先分清四种：

1. **知识错**：换几个条件都失败，规律本身不成立。
2. **条件错**：规律有边界，这次的条件不在适用范围内。
3. **执行错**：操作、测量、数据、代码写错了。
4. **样本不足**：一次失败不能说明什么，再做一两次。

在人际、社会、组织问题里，失败还可能来自力量对比、关系、时机，不一定是想法错——别急着把“没成”归因于“你错了”。

## 7. 第二次飞跃：回到当代现场

第一次飞跃只是“想明白了”；第二次飞跃才回答“它在今天对不对、有没有用”。

- **换现场，不只是换条件**：从历史现场走到当代现场——今天的工具、数据、约束、前沿问题。
- **面向现代化、面向未来、面向当代前沿科学与工程**：用今天真实的问题检验它，而不是用二十年前的“现代”案例。
- **要改变一个真实的东西**：一个决定、一个产物、一个做法；不是再解释一遍，也不是换个例子再做一道。
- **检验的标准**：知识能不能指导当代行动，得到预期结果。
- **前沿的分寸**：区分成熟应用、探索中、概念；不装懂、不追热点、标来源与日期。
- 认识世界的目的，是为了改造世界——学习也一样：最终要改变他在今天能做的事。

## 8. 循环与停止

- 第二次实践之后，新的结果就是新的感性材料，进入下一轮“看见 → 命名”。
- 每轮应该比上一轮高一级：更少的提示、更难的條件、更真实的场景、更靠近前沿。
- 什么时候停：知识能稳定指导目标场景中的行动；或者他的目标已经达到；或者继续边际收益很低。
- 不要为了“循环”而循环；也不要在第一次成功后就宣布“学会了”。

## 9. 三个例子

### 9.1 TCP 为什么三次握手

- **历史入境**：1970 年代，两台机器要传文件；线路会丢包、会重复；你只有“发”和“收”。
- **第一次实践**：先设计两次握手。A 发，B 回，A 知道 B 收到了——**B 知道 A 收到了吗？**
- **看见**：如果 B 的回复丢了，A 重发；B 收到两个请求，可能以为是两个连接。
- **命名**：三次是“双方都确认对方收到、并能同步序号”的最小次数。
- **当代再用**：今天的网络（数据中心、QUIC 0-RTT、卫星链路、IoT）里，1970 年代的哪些假设变了？握手还要几次？0-RTT 换来了什么风险？

### 9.2 航海为什么需要三角学

- **历史入境**：你是 16 世纪的船长，在海上没有 GPS，只有星空、测角仪和一张海图。你要知道“我在哪、走了多远”。
- **第一次实践**：已知两地的纬度差和航向角，你能直接算出距离吗？先试一个简单情形。
- **看见**：角度和距离的关系不是线性的；只靠加减乘除不够。
- **命名**：把角度和边长连起来的那套工具，就是三角学。
- **当代再用**：GPS 定位、机器人运动学、计算机图形学、信号处理——今天的三角学在算什么？三维旋转、傅里叶变换和它是什么关系？

### 9.3 梯度下降为什么这么走

- **历史入境**：你蒙着眼睛站在山谷里，只能感觉脚下的坡度；你要走到谷底，但每一步只能迈固定长度。
- **第一次实践**：站在 x=3，f(x)=x²，坡是 6，步长 0.1，下一步在哪？
- **看见**：你走到的位置，正好是“往坡度反方向走一步”。
- **命名**：这就是梯度下降：x ← x − 步长 × 梯度；负号不是约定，是“下坡”。
- **当代再用**：LLM 训练、强化学习、推荐系统里的梯度下降长什么样？动量、Adam、分布式训练解决了哪些当年没有的问题？

## 10. 反模式

- **先讲完知识再练习**：把实践当“应用题”，知识当入场券。
- **冷启动盲猜**：没给处境、目的、约束，就问“你猜会怎样”。
- **一个例子就命名**：材料不够就下结论。
- **实践完老师直接总结**：不让他先说看到了什么。
- **命名完就结束**：没有“再用一次”，知识停在名词上。
- **把“再用”做成练习**：换个例子刷一遍，不检验真实行动。
- **一失败就改知识**：不分知识错、条件错、执行错、样本不足。
- **只做一类实践**：把学习窄化成做题或写代码。
- **历史背景讲成故事会**：讲得热闹，但不服务这次实践的目的。
- **第二次实践只是改数字**：条件换了一下，现场还是历史现场。
- **用二十年前的“现代”案例冒充当代**：不查当前工具、当前数据、当前版本。
- **追热点、装懂前沿**：不知道 SOTA 就说不知道，不编“某公司”“某突破”。

## 11. 和其它部分的关系

- **genesis（规则是答案）**：第 1 步“历史入境”的工具，不是独立的历史课；历史现场是第一次实践，命名后要到当代现场再用一次。
- **curiosity（求知欲）**：第 3 步的差异、第二次实践里留缺口。
- **knowledge-map（知识地图）**：节点上“要解决的问题”，就是历史入境的素材。
- **eval（评测）**：看两次实践——第一次有没有历史背景/目的/角色，第二次有没有换成当代现场；材料够不够；有没有“循环”。

## 12. 一句话

> 先调查他的真实处境，再让他站在历史问题里；先让他动手，再让他看见；先让他自己命名，再让他用这个名字，去解一个当代的问题。
