# 实践循环：先入境，再动手；先做，再懂，再用

## 0. 一句话

不是“先学知识，再练习”，是**先入境做一次，再从结果里长出知识，再用知识做第二次**。

原则不变：能力 + 求知欲。这一份讲的是方法。

## 1. 五步

1. **入境**：给一个生动的历史/现实处境——谁、在什么约束下、要解决什么问题、这次要达成什么。让他“在里面”，不是旁观。
2. **动手**：做一个具体的选择、计算、设计或判断。带着背景和目的去做，**不是盲猜**。
3. **看见**：结果如何？和预期差在哪？先让他说看到了什么，不要替他总结。
4. **命名**：理论在此刻出现，解释刚才发生了什么。知识是这次实践的“事后总结”，不是开场讲义。
5. **再用**：换一个条件或场景，用刚得到的知识再做一次更好的选择；留下一个问题，或下一次实践的入口。

## 1.5 两次飞跃与循环

毛泽东《人的正确思想是从哪里来的？》（1963）把认识过程写成两次飞跃：

1. **物质 → 精神**：感性材料积累多了，产生飞跃，变成理性认识（思想、理论、计划）。
2. **精神 → 物质**：把认识放回实践，看能否得到预期结果；这是检验真理的唯一办法。
3. **反复**：一个正确的认识，往往要经过“实践 → 认识 → 实践 → 认识”的多次反复，才能完成。

对应到五步：

- **入境 + 动手 + 看见** = 积累感性材料（材料要厚，不是一次就够）；
- **命名** = 第一次飞跃：先让学习者自己试着说出规律，老师再补；
- **再用** = 第二次飞跃，也是检验：知识对不对，看它能不能指导下一次实践；
- **循环** = 再用会产生新的感性材料，进入下一轮；每轮应比上一轮高一级。

两个提醒：

- **命名不是老师总结**：先让他说，说错也是材料；老师补的是名字和边界。
- **再用不是练习题**：它是检验知识的地方；失败先查条件 / 执行，再改知识。

原文（节选）：

> 一个正确的认识，往往需要经过由物质到精神，由精神到物质，即由实践到认识，由认识到实践这样多次的反复，才能够完成。
> —— 毛泽东《人的正确思想是从哪里来的？》（1963）

## 2. 第一次实践的三件套

缺一个，就会退化成“盲猜题”或“应用题”：

- **背景**：为什么会有这个问题？当时的人被什么卡住？
- **目的**：这次实践要达成什么？一个可见结果，或一个明确的判断。
- **角色 / 约束**：你是谁？手上有什么？不能做什么？

举例：

- 不是“你猜 TCP 要几次握手？”
- 而是“你是 1970 年代的网络工程师，两台机器要传文件，线路会丢包、会重复。你只有‘发’和‘收’两个动作。先设计一个握手，两次够吗？”

## 3. 不盲猜

- 不冷启动问“你猜会怎样”；先给处境、目的、约束。
- 猜要在角色里猜：“作为船长，你判断……”而不是“你随便猜”。
- 猜之前信息要够，猜之后要有结果可对；否则不是实践，是抽签。

## 4. 三个例子

### 4.1 TCP 为什么三次握手

- **入境**：1970 年代，两台机器要传文件；线路会丢包、会重复；你只有“发”和“收”。
- **动手**：先设计两次握手。A 发，B 回，A 知道 B 收到了——**B 知道 A 收到了吗？**
- **看见**：如果 B 的回复丢了，A 重发；B 收到两个请求，可能以为是两个连接。
- **命名**：三次是“双方都确认对方收到、并能同步序号”的最小次数。
- **再用**：如果网络可靠、或者已有身份认证，还需要三次吗？QUIC 为什么能 0-RTT？

### 4.2 航海为什么需要三角学

- **入境**：你是 16 世纪的船长，在海上没有 GPS，只有星空、测角仪和一张海图。你要知道“我在哪、走了多远”。
- **动手**：已知两地的纬度差和航向角，你能直接算出距离吗？先试一个简单情形。
- **看见**：角度和距离的关系不是线性的；只靠加减乘除不够。
- **命名**：把角度和边长连起来的那套工具，就是三角学（正弦、余弦、正切表）。
- **再用**：如果只能测一个角，还需要什么信息？如果地球是平的，结论会变吗？

### 4.3 梯度下降为什么这么走

- **入境**：你蒙着眼睛站在山谷里，只能感觉脚下的坡度；你要走到谷底，但每一步只能迈固定长度。
- **动手**：站在 x=3，f(x)=x²，坡是 6，步长 0.1，下一步在哪？
- **看见**：你走到的位置，正好是“往坡度反方向走一步”。
- **命名**：这就是梯度下降：x ← x − 步长 × 梯度；负号不是约定，是“下坡”。
- **再用**：步长改成 10，会怎样？为什么步子太大会发散？

## 5. 反模式

- **先讲完知识再练习**：把实践当“应用题”，知识当入场券。
- **冷启动盲猜**：没给处境、目的、约束，就问“你猜会怎样”。
- **实践完老师直接总结**：不让他先说看到了什么，知识变成老师的独角戏。
- **命名完就结束**：没有“再用一次”，知识停在名词上。
- **历史背景讲成故事会**：讲得热闹，但不服务这次实践的目的。
- **目的不清**：“你来试试”而不是“你要达成 X”。

## 6. 和其它部分的关系

- **genesis（规则是答案）**：第 1 步“入境”的工具，不是独立的历史课。
- **curiosity（求知欲）**：第 3 步的差异、第 5 步的“再用”里留缺口。
- **knowledge-map（知识地图）**：节点上“要解决的问题”，就是入境素材。
- **eval（评测）**：看第一次实践有没有背景/目的/角色，以及有没有“再用”。

## 7. 一句话

> 先让他站在问题里，再让他动手；先让他看见，再给他名字；最后让他用这个名字，再做一次。
