# 实践循环：从实践中来，再回到实践中去

## 0. 一句话

不是“先学知识，再练习”，是**先入境做一次，从结果里长出知识，再用知识做第二次**；一次不够，反复循环。

原则不变：能力 + 求知欲。这一份讲的是方法，思想依据是毛泽东《人的正确思想是从哪里来的？》（1963）。

## 1. 认识论骨架

三条，按顺序：

1. **知识只能从实践中来。** 不是天上掉的，也不是头脑里固有的；是人在做事、交往、实验中，先得到感性材料。
2. **两次飞跃。** 感性材料积累多了，飞跃成理性认识（第一次）；理性认识回到实践、看能不能得到预期结果（第二次）。第二次比第一次更重要——只有它能检验第一次。
3. **反复循环。** 一个正确的认识，往往要经过“实践 → 认识 → 实践 → 认识”的多次反复，才能完成。

原文（节选）：

> 人的正确思想，只能从社会实践中来……
> 一个正确的认识，往往需要经过由物质到精神，由精神到物质，即由实践到认识，由认识到实践这样多次的反复，才能够完成。
> —— 毛泽东《人的正确思想是从哪里来的？》（1963）

我们只取这个**认识论结构**，不搬文章里的政治内容。

## 2. 五步（前面还有一次“调查”）

0. **调查**：先弄清他的真实处境——想做什么、手上有什么、卡在哪、能投入多少。入境不是编一个场景，是从他的真实条件里长出来。
1. **入境**：给一个生动的历史/现实处境——谁、在什么约束下、要解决什么问题、这次实践要达成什么。让他“在里面”，不是旁观。
2. **动手**：做一个具体的选择、计算、设计或判断。带着背景和目的去做，**不是盲猜**。
3. **看见**：结果如何？和预期差在哪？先让他说看到了什么，不要替他总结。
4. **命名**：理论在此刻出现，解释刚才发生了什么；**先让他试着说出规律**，老师再补名字和边界。
5. **再用**：换一个条件或场景，用刚得到的知识再做一次；这一次是检验，不只是练手。

对应两次飞跃：

- 入境 + 动手 + 看见 = 积累感性材料；
- 命名 = 第一次飞跃（感性 → 理性）；
- 再用 = 第二次飞跃（理性 → 实践），也是检验；
- 循环 = 再用产生新的感性材料，进入下一轮，每轮高一级。

## 3. 第一次实践的三件套

缺一个，就会退化成“盲猜题”或“应用题”：

- **背景**：为什么会有这个问题？当时的人被什么卡住？
- **目的**：这次实践要达成什么？一个可见结果，或一个明确的判断。
- **角色 / 约束**：你是谁？手上有什么？不能做什么？

不是“你猜 TCP 要几次握手？”，而是“你是 1970 年代的网络工程师，两台机器要传文件，线路会丢包、会重复。你只有‘发’和‘收’。先设计一个握手，两次够吗？”

## 4. 材料要够，再飞跃

感性材料不够，飞跃就是拍脑袋。

- 命名之前，尽量有 **2–3 个具体观察/案例/变体**：同一规律在不同条件下都出现，才值得命名。
- 一个数据点只能算轶事，不能算规律；一次成功/失败也不够。
- 材料可以是：跑出来的结果、画出来的图、算出来的数、别人的反馈、历史上的多个案例。
- 但也不要收集到瘫痪：够解释当前问题就停，剩下的留给下一轮。

## 5. 三类实践

不要把“实践”窄化成写代码或做题。至少三类：

| 类型 | 做什么 | 例子 |
|---|---|---|
| **造物**（生产/工程） | 做出一个能跑、能用、能看的东西 | 跑通脚本、搭一个电路、写一篇文章 |
| **交往**（社会） | 一次真实的沟通、说服、协作、教学 | 给外行讲清、说服同事、教 AI |
| **实验**（科学实验） | 一个可验证的预测、对照、复现 | 改一个参数、做 A/B、复现结果 |

三类都可以是“第一次实践”。选哪类，看他的目标和真实条件。

## 6. 失败怎么读

失败不是“再讲一遍”的信号，先分清四种：

1. **知识错**：换几个条件都失败，规律本身不成立。
2. **条件错**：规律有边界，这次的条件不在适用范围内。
3. **执行错**：操作、测量、数据、代码写错了。
4. **样本不足**：一次失败不能说明什么，再做一两次。

在人际、社会、组织问题里，失败还可能来自力量对比、关系、时机，不一定是想法错——别急着把“没成”归因于“你错了”。

## 7. 第二次飞跃更重要

第一次飞跃只是“想明白了”；第二次飞跃才回答“它到底对不对、有没有用”。

- 再用的时候，要**改变一个真实的东西**：一个决定、一个产物、一个做法。
- 不是“再解释一遍”，也不是“换个例子再做一道”。
- 检验的标准是：知识能不能指导下一次行动，得到预期结果。
- 认识世界的目的，是为了改造世界——学习也一样：最终要改变他能做的事。

## 8. 循环与停止

- 再用之后，新的结果就是新的感性材料，进入下一轮“看见 → 命名”。
- 每轮应该比上一轮高一级：更少的提示、更难的條件、更真实的场景。
- 什么时候停：知识能稳定指导目标场景中的行动；或者他的目标已经达到；或者继续边际收益很低。
- 不要为了“循环”而循环；也不要在第一次成功后就宣布“学会了”。

## 9. 三个例子

### 9.1 TCP 为什么三次握手

- **入境**：1970 年代，两台机器要传文件；线路会丢包、会重复；你只有“发”和“收”。
- **动手**：先设计两次握手。A 发，B 回，A 知道 B 收到了——**B 知道 A 收到了吗？**
- **看见**：如果 B 的回复丢了，A 重发；B 收到两个请求，可能以为是两个连接。
- **命名**：三次是“双方都确认对方收到、并能同步序号”的最小次数。
- **再用**：如果网络可靠、或者已有身份认证，还需要三次吗？QUIC 为什么能 0-RTT？

### 9.2 航海为什么需要三角学

- **入境**：你是 16 世纪的船长，在海上没有 GPS，只有星空、测角仪和一张海图。你要知道“我在哪、走了多远”。
- **动手**：已知两地的纬度差和航向角，你能直接算出距离吗？先试一个简单情形。
- **看见**：角度和距离的关系不是线性的；只靠加减乘除不够。
- **命名**：把角度和边长连起来的那套工具，就是三角学。
- **再用**：如果只能测一个角，还需要什么信息？如果地球是平的，结论会变吗？

### 9.3 梯度下降为什么这么走

- **入境**：你蒙着眼睛站在山谷里，只能感觉脚下的坡度；你要走到谷底，但每一步只能迈固定长度。
- **动手**：站在 x=3，f(x)=x²，坡是 6，步长 0.1，下一步在哪？
- **看见**：你走到的位置，正好是“往坡度反方向走一步”。
- **命名**：这就是梯度下降：x ← x − 步长 × 梯度；负号不是约定，是“下坡”。
- **再用**：步长改成 10，会怎样？为什么步子太大会发散？

## 10. 反模式

- **先讲完知识再练习**：把实践当“应用题”，知识当入场券。
- **冷启动盲猜**：没给处境、目的、约束，就问“你猜会怎样”。
- **一个例子就命名**：材料不够就下结论。
- **实践完老师直接总结**：不让他先说看到了什么。
- **命名完就结束**：没有“再用一次”，知识停在名词上。
- **把“再用”做成练习**：换个例子刷一遍，不检验真实行动。
- **一失败就改知识**：不分知识错、条件错、执行错、样本不足。
- **只做一类实践**：把学习窄化成做题或写代码。
- **历史背景讲成故事会**：讲得热闹，但不服务这次实践的目的。

## 11. 和其它部分的关系

- **genesis（规则是答案）**：第 1 步“入境”的工具，不是独立的历史课。
- **curiosity（求知欲）**：第 3 步的差异、第 5 步的“再用”里留缺口。
- **knowledge-map（知识地图）**：节点上“要解决的问题”，就是入境素材。
- **eval（评测）**：看第一次实践有没有背景/目的/角色，材料够不够，有没有“再用”和“循环”。

## 12. 一句话

> 先调查他的真实处境，再让他站在问题里；先让他动手，再让他看见；先让他自己命名，再让他用这个名字，改变一个真实的东西。
