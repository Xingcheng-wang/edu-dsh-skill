# 认知进步：具体上下文 + 抽象概述 + 两次飞跃

## 0. 一句话

进步不是“今天学了 X”，是**在某个具体场景里，他的认知发生了一次可指认的变化**。

## 1. 什么算进步

- **第一次飞跃（感性 → 理性）**：从具体经验/操作里提炼出规则、概念、边界；能解释“为什么”。
- **第二次飞跃（理性 → 实践）**：把刚命名的知识用到真实/当代任务里，改变了做法、产物或决定。
- **不算**：听了、看了、点头、做完题、花了时间、觉得“懂了”。

## 2. 一条记录

| 字段 | 要求 | 字数 |
|---|---|---|
| **上下文** | 谁、在哪（文件/行/任务/回答）、发生了什么 | ≤160 字 |
| **概述** | 哪次飞跃 + 认知变化；抽象到能迁移 | ≤80 字 |
| **证据**（可选） | 文件行、产物路径、测试结果、观察 | ≤160 字 |
| **leap** | `first` 或 `second` | — |
| **topic / node** | 挂到知识地图的哪个节点（可选） | — |

字数不是形式：**上下文够具体到能复查，概述够抽象到能迁移**；超了，通常说明还没想清楚。

概述里不要重复“第一次飞跃：/第二次飞跃：”，CLI 会自动去掉前缀；引用块里的日期行已经标了。

## 3. 笔记文件与格式

- 文件名：**`<学习主线>（学习主线）进步记录.md`**，放在 `<EDU_HOME>/learner/` 下。
  - 例：`微积分（学习主线）进步记录.md`、`网络（学习主线）进步记录.md`。
  - 数据仍在 `<EDU_HOME>/learner/progress.jsonl`；笔记是生成的视图。
- **一条记录一个 Markdown 引用块**，不用标题、不用小标题：

```markdown
> 2026-11-20 · 第一次飞跃
> 上下文：在 retry.py 第 6 行，他先猜异常会被吞掉，跑了一次发现异常真的没了
> 概述：从猜行为到能说出 try/except 的边界
> 证据：D:\work\demo\retry.py:6

> 2026-11-21 · 第二次飞跃
> 上下文：他把异常处理改到真实上传脚本，先加幂等键再重试，避免重复扣款
> 概述：把重试边界用到一个会重复扣款的真实动作里
```

- 多条记录之间空一行；按时间顺序追加。
- 旧版 `learner/progress.md` 会在下一次生成时自动清理；数据不会丢。

## 4. 什么时候记

- 他纠正了一个预测或误解。
- 他能用自己的话说出规律、边界或代价。
- 他把知识用到一个新场景/真实任务，做法、产物或决定变了。
- 他问出一个能接下去的问题（可选；属于好奇心，不一定是进步）。

**可以频繁**：一次会话可以记多条，只要有真正的变化；但不要为了数量凑，也不要每轮例行一条。

## 5. 怎么显示

- `progress show`：打印每个笔记文件的绝对路径 + 引用块内容。
- `state`：最近一条进步 + 对应文件路径。
- `doctor`：记录条数（只用于诊断）。
- 对话里记录后给一行：`进步｜第一次飞跃：<概述>`。

## 6. 命令与路径

```bash
progress --action add \
  --context "在 retry.py 第 6 行，他先猜异常会被吞掉，跑了一次发现异常真的没了" \
  --leap first \
  --summary "从猜行为到能说出 try/except 的边界" \
  --evidence "D:\work\demo\retry.py:6" \
  --topic calculus --node retry --session last --consent outline

progress --action show [--limit 50] [--json]
```

- 数据：`<EDU_HOME>/learner/progress.jsonl`
- 笔记：`<EDU_HOME>/learner/<学习主线>（学习主线）进步记录.md`

## 7. 正反例

**好**：

```markdown
> 2026-11-20 · 第一次飞跃
> 上下文：在 retry.py 第 6 行，他先猜异常会被吞掉，跑了一次发现异常真的没了
> 概述：从猜行为到能说出 try/except 的边界
```

**坏**：

```markdown
# 今天的学习进步
## 学到了 try/except
- 今天学了异常处理，收获很大。
```

问题：用了标题；上下文空泛；概述是复述；没有飞跃。

## 8. 反模式

- 为了数量每轮都记，日志代替判断。
- 上下文写“今天学了 X”，没有场景。
- 概述复述上下文，没有抽象。
- 飞跃标错：把“做完练习”当第二次飞跃；第二次必须改变真实做法/产物/决定。
- 用进步条、百分比、连续天数、排行榜展示。
- 未经同意记录；`off` 还写。
- 记“他很聪明 / 他很努力”这类人格判断。
- 用标题/小标题把笔记写成报告；一条记录应能一眼扫完。

## 9. 和其它部分的关系

- **实践循环**：进步发生在“看见→命名”（第一次）或“再用”（第二次）。
- **知识地图**：`topic` 用地图 id，笔记名会取地图标题；记录挂到 `node`。
- **画像 / 路线图**（后续）：进步记录是画像的证据来源。
- **评测**：4.15 只评审，不打分。

## 10. 一句话

> 具体到能复查，抽象到能迁移；一条记录一个引用块，能频繁，但不凑数。
