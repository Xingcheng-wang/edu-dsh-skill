# 规则是答案：还原智慧诞生的现场

## 0. 一句话

任何规则、定义、公式、约定，都不是“本来就这样”，而是**某个人在某个处境下，为了解决某个问题，在一堆不完美的选项里选的一个**。

你的任务不是宣布答案，是把他带回那个处境。

## 1. 冷知识与热思考

- **冷知识**：结论 + 用法。“导数的定义是……”
- **热思考**：问题 + 备选 + 代价 + 抉择。“当时被什么问题卡住？还能怎么做？为什么选了这个？牺牲了什么？”

理解 = 知道它在回答什么问题。
共鸣 = 他也在那个处境里，自己做过一次选择。

## 2. 五步还原

1. **背景**：谁、什么时候、被什么问题卡住？具体到疼。
2. **备选**：当时有哪些做法？各自代价是什么？至少两个，最好三个。
3. **抉择**：为什么是它赢？不是“因为它对”，是“在这些约束下更划算”。
4. **代价**：它牺牲了什么？谁承担？什么时候失效？
5. **改写**：如果是你，会怎么选？改一个约束，会变成什么？

**一次不要五步全上。** 按他的状态选一到两步：先给背景和问题，等他猜；或者先给两个备选，让他选。

## 3. 历史素材的纪律

- 只讲可考的；不确定就标 `[?]`，说“我记得是……不确定”。
- 不用“自古以来”“伟人灵光一现”“显然”。
- 展示争论、失败、被淘汰的方案；历史不是一条直线。
- 区分“当时的理由”和“后来的合理化”。
- 不编故事、不编引文、不编日期；宁可少讲。
- 不把某一个文明当默认；注意并行的方案。

## 4. 批判思维四问

- 它解决了什么？**没解决什么？**
- 代价是什么？谁受益、谁承担？
- 什么条件下会失效、反噬？
- 有没有被压制的替代方案？为什么没被选？

## 5. 创新三练

- **改约束**：网络可靠 / 内存无限 / 人不犯错 / 没有时间压力，会怎么设计？
- **组合**：把两个方案拼起来，会更好还是更糟？
- **反向**：如果目标相反（最大化速度 / 最小化成本 / 最大化公平），会得到什么？

## 6. 四个现场

### 6.1 为什么极限要 ε-δ

- **背景**：17–18 世纪的微积分靠“无穷小”直观运算；Berkeley 1734 年嘲笑它是“消失量的鬼魂”；19 世纪要给分析一个严格基础。
- **备选**：无穷小、直观极限、ε-δ 的有限不等式（Cauchy/Weierstrass）、20 世纪的非标准分析（Robinson）。
- **抉择**：ε-δ 把“无限接近”翻译成“任给 ε，存在 δ”，避开了“无穷小到底是不是零”。
- **代价**：直观性下降、入门变难，很容易被教成一条要背的规则。
- **批判**：它真的抓住了“接近”的直觉吗？非标准分析是不是另一种合法答案？
- **改写**：如果今天重写，你会用游戏、可视化、程序来定义极限吗？

### 6.2 为什么 Python 用缩进

- **背景**：Guido 设计 Python（受 ABC 语言影响），目标是可读、少符号噪音。
- **备选**：花括号（C/Java）、`begin/end`（Pascal）、强制缩进（Python）。
- **抉择**：缩进把“结构”直接变成“看得见的形状”，减少括号风格之争。
- **代价**：对复制粘贴、格式化敏感；混用 tab/space 会出事。
- **批判**：可读性真的来自缩进，还是来自规范、工具和团队习惯？
- **改写**：如果团队已经有自动格式化器，约束变了，你还会选强制缩进吗？

### 6.3 为什么 TCP 要三次握手

- **背景**：早期网络不可靠，需要双方确认“我发的你收到了、你发的我也收到了”，还要防止旧连接的重复包。
- **备选**：两次握手、三次握手、四次握手。
- **抉择**：三次是“双方都确认对方收到并能同步序号”的最小次数。
- **代价**：多一个往返延迟、连接状态；也留下了 SYN flood 的攻击面。
- **批判**：QUIC 的 0-RTT 改了哪些约束？安全性换来了什么？
- **改写**：如果网络可靠、或者已有身份认证，还需要三次吗？

### 6.4 为什么法律要无罪推定

- **背景**：启蒙时期对纠问式审判与刑讯的反思（如 Beccaria 1764），国家权力远大于个人。
- **备选**：有罪推定 / 纠问、无罪推定、疑罪从无 / 从有。
- **抉择**：把错判的成本更多压给更有能力承担的一方（国家），降低冤案。
- **代价**：可能放过真有罪的人；对受害者不总是“解气”。
- **批判**：律师资源、财富差距会不会让“推定”变成形式？公共安全紧急时怎么权衡？
- **改写**：如果错判可以完全逆转，规则会怎么变？

## 7. 反模式（“规则怪谈”）

- “规则就是这样 / 规定如此 / 考试要考。”
- 只讲结论，不讲它要解决什么问题。
- 把历史讲成伟人神话：灵光一现、天才独造。
- 只讲成功方案，不讲被淘汰的备选。
- 为了故事好听，编细节、编对话、编日期。
- 把“当时的选择”说成“唯一正确的真理”。
- 用“批判”否定一切，却不给建设性的替代。

## 8. 和地图、好奇心、实践循环的关系

- 它是实践循环第 1 步（入境）的工具：先还原问题，再让他动手。
- 知识地图的每个节点，都可以带一句“它要回答的问题”——建节点时用：
  `map --action add --topic ... --node ... --title ... --note "要解决的问题：……"`
- 好奇心常常从“当时的代价”和“没解决的部分”里长出来：讲完代价，留一个真问题。

## 9. 一句话

> 不要告诉他“规则是这样”，带他回到“当时只能这样，或者那样”。
