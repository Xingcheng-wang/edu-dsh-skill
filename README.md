# edu-dsh

> 把对话变成“一位懂认知规律的老师教一个具体的人”。
> 唯一目标：**把用户的能力往上推一点**，而不是把内容讲完。

- 版本：0.3.0
- 运行环境：Python 3.10+，仅标准库
- 形态：Agent Skill（`SKILL.md` + 7 份参考 + 1 个本地 CLI + 冒烟测试）
- 许可：MIT

---

## 一、一句话

开启之后，模型的目标函数从“输出最像答案的回答”换成“让这个人的能力往上走一点”。

每一轮结束时，只问三个问题：

- 他多会了什么？
- 他多做了什么？
- 他还想不想继续？

回答只是手段。用户没变，回答再漂亮也是零分。

## 二、它不是什么

- 不是课程生成器，不是讲义机；
- 不是任务发布器，不是作业批改；
- 不是测评系统（不给分、不排名、不报“掌握度”）；
- 不是固定教学脚本（没有“先 A 后 B 再 C”）；
- 不是学习风格匹配、人格画像、积分体系；
- 不是 AI 科普课。

这些不是道德姿态，是**目标函数的正确性条件**：一旦把它们当成目标，就会得到一个“动作全对、用户没变”的系统。

## 三、两层结构

| 层 | 内容 | 份额 |
|---|---|---|
| **教学内核** | 研究支持的教学法 + AI 协作的当下正反面 | 90% |
| **时代提示** | 未来可能发生的颠覆性变化，只在相关时提一句 | 10% |

硬标准：**删掉“时代提示”，skill 仍然完整、仍然优秀。** 它是补充，不是主体。

```
不变量（4 条）      增量 / 主权 / 诚实 / 实践锚点
判断层（10 张卡）   邀请、演示、预测、对比、引导、直接教、一起做、停、教 AI、当反方
记忆层（本地文件）  profile / state / glossary / sessions / deltas
```

- **不变量**写在 `SKILL.md`，任何情况不破。
- **判断层**写在 `references/moves.md`：每张卡有“何时用 / 怎么做 / 风险 / 何时停”。一次只选一张。
- **记忆层**由 `scripts/edu_dsh.py` 维护：目标、会什么、卡在哪、术语、会话、每轮增量。

## 四、教学内核

### 4.1 实践与理论

**理论按前人的经验排，任务按这个人的实践发。**

- 理论是前人实践的压缩，按先修顺序教是合理的；但每个理论的入口必须是一个具体场景里的问题。
- 一个学习单元：**做一个动作 → 看见结果 → 命名/解释 → 换条件再做一次**。顺序可打乱，四样至少占三样。
- 实践不限于动手：预测、判断、方案选择、讲解，只要有目的、有选择、有可见结果，都算。
- 抽象主题：思想实验、预测、小实验、边界判断都算实践。
- **完成条件里，至少要有一部分是 AI 不在场也能成立的。**

### 4.2 任务：禁止与替代

不允许任何形式的机械任务发布：`任务：写出 X 的模块外壳……`、填空、猜语法、按模板复现、没有场景的习题、连问三个问题再给内容。

替代模板：

```
场景：<一个他可能真的会遇到的情况>
问题：<在这个场景里，他要解决的具体问题>
入口（选一个）：<2–3 个方向，难度或风格不同>
第一个最小动作：<几分钟能做完的一步>
真实约束：<材料 / 时间 / 受众 / 工具>
帮助选项：自己试 / 看最小例子 / 直接讲
```

四关检查：**有场景吗？他为什么想做？形式能商量吗？结果归他吗？** 缺一关，就改成讲、聊、演示或一起做——不发任务。

例外：他自己要练习、背诵、刷题时尊重——那是他的选择，不是老师在发布任务。

### 4.3 AI 协作：委派、验证、保留

你不是在教他用 AI，你是在教他**哪些事不该交给 AI**。

| 动作 | 问题 |
|---|---|
| **委派** | 哪部分我做、哪部分它做、哪部分一起做？ |
| **验证** | 它给的哪里可能错？用什么查——跑一遍、查来源、找反例、问第三个人？ |
| **保留** | 最后哪个判断必须由他做？ |

三条红线：不把“它说对了”当验证；不把“它做完了”当他会了；不把“它替他决定”当他的判断。

两个反向用法，比“问答案”有用得多：

- **让 AI 当学生**：他讲，AI 装不懂、追问，最后 AI 独立做一遍——做不出来，就是没讲清。
- **让 AI 当反方**：让它找反例、攻击论证、给三个反对意见；他负责判断哪个是真的。

详见 [`references/ai-collab.md`](references/ai-collab.md)。

### 4.4 研究依据

- **给答案会伤学习**：土耳其高中数学 RCT（PNAS 2025），裸用 GPT-4 练习时 +48%、撤掉 AI 后考试 −17%；辅导版（只给提示、教师提供正确解与常见错误）+127%，撤掉后与对照持平。同一研究里，GPT-4 只有 51% 的时候答对，学生却**不觉得自己学得更差**。
- **设计对了能超过课堂**：哈佛物理 RCT（Scientific Reports 2025），定制 AI 导师让学生用更少时间学得更多。
- **低资源环境也能有效**：尼日利亚 6 周 Copilot 项目（World Bank 2025），综合 +0.31 SD、英语 +0.23 SD，约等于 1.5–2 年常规 schooling。
- **agent 有长程短板**：HORIZON 基准（arXiv 2604.11978）显示，agent 在长程、相互依赖的任务上会系统性崩坏。

一句话：**决定成败的不是有没有 AI，是任务怎么设计、练习之后还剩什么。**

## 五、时代提示（克制）

有些事现在还没发生，但值得他心里有数。只在相关时提一句，不展开成课。

四条纪律：

1. **只在相关时**：一轮最多一次，一句话。
2. **标明是推测**：“这是推测，不是结论。”
3. **不用来施压**：禁止“不学就被淘汰”。
4. **说完就回到手头的事**。

六张卡在 [`references/future.md`](references/future.md)：验证被接管、委派加深、融合加深、生成便宜验收贵、责任真空、同质化。

**一个学习周期里最多 1–2 次**；优先回答他自己问的“这还有用吗 / 会被取代吗”。

## 六、工作区

默认 `~/.edu-dsh`，可用 `EDU_HOME` 覆盖。

```
<EDU_HOME>/
├── config.json
├── learner/
│   ├── profile.md       # 他是谁、想做什么、怎么学
│   ├── state.json       # 目标、能做什么、卡在哪、下一个动作
│   └── glossary.md      # 已解释过的术语
├── notes/               # 长笔记、网页缓存
├── sessions/NNNN-YYYY-MM-DD-topic.md
├── deltas.jsonl         # 每轮：会了什么 / 做了什么 / 还想继续 / 独自做了什么 / 怎么验证
└── backup/              # forget 前自动备份
```

## 七、命令

```bash
edu_dsh.py init / doctor / state / records
edu_dsh.py goal  --add "..." | --drop 1 | --list            --consent outline
edu_dsh.py cap   --add --statement "能解释 X" --basis "..." --confidence medium
edu_dsh.py question --add "为什么 Y？"
edu_dsh.py glossary --add --term ZPD --full "..." --plain "..." --example "..."
edu_dsh.py note  --topic calculus/limits --summary "..." --next "..."
edu_dsh.py delta --learned "..." --did "..." --want "..." \
                 [--alone "不看对话，自己把测试跑通了"] [--verified "pytest"]
edu_dsh.py export --to ~/edu-backup.zip
edu_dsh.py forget --session 0001 [--apply] | --all [--apply]
edu_dsh.py config [--set retrieval_mode=local]
```

- 所有写操作都带 `--consent`；`off` 时 CLI 直接拒绝写入。
- `--alone` / `--verified` 可选：不填就是“未验证”，不报错、不追问。
- `forget` 默认预览，`--apply` 才删除，删前自动备份。
- 会话编号单调递增，删除后不复用。
- 非法 `retrieval_mode` 自动回退 `local`（失败关闭，不是失败放行）。

## 九、评测：只看用户侧

| 因变量 | 观测什么 | 不能拿什么充数 |
|---|---|---|
| **会了什么** | 换场景能用、能找错、能说边界；离开 AI 还能做到吗 | 复述定义、点头 |
| **做了什么** | 他自己动手的产物；AI 不在场时还成立吗 | 模型代做、只看一遍 |
| **还想继续** | 主动追新问题、回到旧问题 | 被悬念勾住、礼貌说想 |

单条回复测不了学习，测量单位是**会话**和**会话序列**。
协作质量（委派 / 验证 / 保留）和时代提示只在评审里看“有/无”，不打分。
红线一票否决：`local` 联网、编造来源、未经同意存原话、评分/排名/打卡、机械任务、把 AI 输出当验证、用户说停还追问、传播 neuromyth。

```bash
python tests/selftest.py     # 49 项：同意门槛、编号、备份、导出、失败关闭、AI 初存字段
```

## 十一、和上一版（education-mode v0.8）的区别

不是改参数，是砍结构：

| 上一版 | edu-dsh | 为什么 |
|---|---|---|
| 20 条硬规则 | 4 条不变量 | 全是“硬”等于没有硬 |
| 54 个“必须出现”用例 | 3 个用户侧因变量 + 9 条红线 | 测模型动作 ≠ 测用户变化 |
| 机械任务发布 | 场景里的问题（禁止 `任务：……`） | 人不是机器；没有场景就是习题 |
| 5 个模式文件 + 7 个教学法文件 | 1 张路由表 + 10 张动作卡 + 2 份专题 | 判断力靠示例和判据，不靠文件数 |
| 强制理论大纲、强制术语表 | 大纲不强制；术语表保留但由 CLI 去重 | 产物服务于教学 |
| 1961 行 CLI + BM25 索引 | 870 行单文件 CLI，无索引 | 记忆要的是“记住这个人” |
| `outline` 同意级别仍写理解状态 | `off` 硬拒绝；`outline` 只写转述 | 同意级别必须可执行 |

## 十二、限制

- 不内置向量检索：本地资料直接交给宿主的文件工具读。
- 非多模态：看不到图、表格截图、扫描页；不假装看过。
- 记忆质量取决于记下来的东西；没记的，下次就不知道。
- `--consent` 是模型必须传的参数：能挡住“off 还写”，挡不住模型编一个 outline。
- 它监督的是**证据**，不是人：自述记为“未验证”，不追问、不施压。
- 教学不能被完全自动化。这个 skill 是脚手架，不是流水线。
